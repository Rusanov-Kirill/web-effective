# Marvel Comics and Characters Information Site

> **Описание проекта**: Проект представляет собой веб-сайт, где пользователи могут читать информацию о различных персонажах и комиксах Marvel. Сайт предлагает просмотр списка персонажей и комиксов, а также краткой информации о каждом конкретном персонаже и комиксе.

### Основные функции:
- Просмотр информации о персонажах и комиксах Marvel.
- Просмотр информации какой герой участвовал в каком комиксе, и какие герои участвовали в данном комиксе.
- Поиск комиксов и персонажей по названию.

## Технологии

Проект построен на следующих технологиях:

- **Frontend**: React, MobX, CSS Modules.
- **Типизация**: TypeScript.
- **API**: Интеграция с Marvel API для получения данных о персонажах и комиксах.
- **HTTP-клиент**: axios для работы с API
- **Сборщик**: Vite.

## Требования

Для работы с проектом рекомендуется использовать следующие версии Node.js и npm/yarn:

- **Node.js**: версия 22.x или выше.
- **npm**: версия 10.x или выше / **yarn**: версия 1.22.x или выше.

2. Перейдите в аудиторию проекта:
    ```bash

3. Установить зависимости с нодой:

    npm install

## Запуск

1. Для запуска сервера:
    ```bash

Проект будет доступен по адресу http://localhost:5173/
